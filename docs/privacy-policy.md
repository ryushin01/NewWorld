# 개인정보 처리방침 (초안)

> 앱에 실제로 구현된 동작(2.11.0)을 기준으로 작성한 초안입니다. 법률 검토를 받지 않았으며, `[ ]` 항목을 채우고 검토한 뒤 사용합니다. 앱의 MY → 개인정보 처리방침에서 이 문서를 엽니다.

신세계 앱은 두 가지 방식으로 동작합니다.

- **데모 모드**(서버 설정 없이 배포한 앱과 웹 데모): 아래 정보는 모두 기기(웹 데모는 그 브라우저의 저장소) 안에만 저장되고 운영자에게 전송되지 않습니다. 둘러보기 계정과 기기에서 만든 계정의 비밀번호는 솔트를 붙인 해시로만 저장합니다.
- **서버 모드**: 아래 "서버에 저장하는 정보"를 Supabase 서버에 저장해 여러 기기에서 이어 씁니다.

## 기기에서만 처리하는 정보

| 항목                                            | 목적                                                                                                                                                          |
| ----------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 현재 위치                                       | 지도의 내 위치, 가까운 순 정렬, 여행지 화면의 '지금 현장에 있어요' 표시. 서버에 보내지 않습니다. 현장 인증을 누를 때만 그 순간의 위치를 위 표처럼 저장합니다. |

| 연결이 끊긴 동안의 변경, 마지막으로 받은 데이터 | 오프라인 사용. 기기의 암호화 저장소에 둡니다.                                                                                                                 |

## 보관과 삭제

- MY의 계정 삭제를 실행하면 장소, 기록, 사진, 프로필 사진, 체크리스트, 여정, 현장 인증, 복구 코드와 계정을 바로 삭제합니다.
- MY에서 기록을 CSV로, 전체 데이터를 JSON으로 내보낼 수 있습니다.
- 로그아웃하면 기기의 서버 데이터 사본을 지웁니다. 아직 올리지 못한 변경은 같은 계정으로 다시 로그인할 때 올리기 위해 기기에 남습니다.
- 엽서·여권·뱃지 이미지는 공유 창에서 고른 곳으로만 전달되고, 앱은 만든 이미지를 따로 보관하지 않습니다.
